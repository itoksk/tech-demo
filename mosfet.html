部品を探究

ゲート

ゲート電圧と、ドレイン電流。

ゲートは酸化膜で絶縁されています。この直流の理想モデルではゲート電流は0 A。実際のスイッチング時にはゲート容量の充放電電流が流れます。

「飽和」は、流れが止まることではない。

VDSがVGS − Vthに達すると、ドレイン端でチャネルがピンチオフ。電子はその先の電界でドレインへ運ばれます。MOSFETの飽和はBJTの飽和と異なり、低抵抗のスイッチONを意味しません。

モデルの式・前提・参考資料
Vov = VGS − Vth / k = 2 mA/V²
遮断：VGS ≤ Vth → ID = 0
線形：0 ≤ VDS < Vov → ID = k (Vov VDS − VDS² / 2)
飽和：VDS ≥ Vov → ID = k Vov² / 2（VGS > Vth）

理想的な長チャネル・平面型NMOSの断面。ソースとボディを接地し、2つの理想電圧源でVGS・VDSを独立に設定します。実機のパッケージ・寸法ではありません。チャネル幅、電子数、速度、電界の矢印は説明用の誇張。分離表示でも電気的な計算は同じです。温度、サブスレッショルド電流、ボディ効果、ボディダイオード、ゲート容量の過渡応答、チャネル長変調、降伏は省略しています。
